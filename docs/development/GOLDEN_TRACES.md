# Golden trace verification registry

Status: authoritative scenario registry.

The `GT-*` identifiers describe representative end-to-end behavior. A row is
`VERIFIED` only when executable evidence covers the complete scenario. Unit
pieces or an unavailable production effect are `PARTIAL`; later-stage
scenarios are `NOT DUE`. This registry does not store generated run output.

## Promotion rule

Promoting a trace requires a stable fixture, authoritative input identities,
typed expected observations/outcome, deterministic bounds, effect-boundary
checks where applicable, and CI execution on the platforms claimed. A skipped
probe or a fake-only path cannot promote a live effect scenario to `VERIFIED`.
