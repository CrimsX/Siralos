# 104 — TUI T1: The Shell

Ticket [103](../tickets/103-siralos-tui.md) · entry review [103](103-siralos-tui-entry-review.md) · Map.

> **User-directed 2026-08-31 (session HITL).** T1 of the approved TUI arc: the shell over the live session — transcript pane, input line, status line — with ratatui + crossterm pinned in the CLI crate, the sanitizer/input-queue/command-catalog seams composing unchanged, a pure deterministic render model tested headlessly over TestBackend, an explicit --tui opt-in with non-TTY fallback, no threads, and the blocking-round freeze documented as a T1 limitation.

## 3. Criteria → evidence

| Criterion                                                    | Evidence                                                                                                                                                                                                                                                                                                                            | Status |
| ------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Sanitizer stays single output boundary                       | `tui::TuiSink` appends verbatim; every line entering transcript is already sanitized upstream via `sanitize_for_display` / `TerminalSanitizer` in `drain_events` and slash-command renderers — same code paths as stdio; `tui_sink_appends_sanitized_lines_verbatim` asserts verbatim storage; no unsanitized injection in `tui.rs` | pass   |
| Input queue single owner + command catalog vocabulary source | TUI handles keys locally but submits the Enter line to the same `handle_tui_line` dispatch that calls `ensure_host`/command-catalog paths; no new vocabulary; approvals stay host-gated (no new authority)                                                                                                                          | pass   |
| No threads anywhere in session path                          | `grep -r "thread"` over `crates/siralos-cli` shows no spawn; event loop is `poll` + timeout only; `TUI shell` docs state "NO THREADS"                                                                                                                                                                                               | pass   |
| Non-TTY falls back to stdio frontend                         | `should_use_tui` pure predicate unit-tested (`non_tty_fallback_predicate`); `main.rs` prints diagnostic and calls `run_interactive_stdio`; headless test without real TTY via predicate                                                                                                                                             | pass   |
| Render model deterministic headlessly tested (TestBackend)   | `draw_determinism_same_state_identical_buffer`, `transcript_tail_and_scroll`, `input_line_editing_renders`, `status_line_rendering`, `empty_state_initial_frame` — all over `TestBackend`; `render_to_buffer` helper also deterministic                                                                                             | pass   |

| Stdio path byte-unchanged                                    | All existing `interactive::tests` pass untouched (14 tests); `run_interactive_session` not modified except for additive TUI entry; `cargo test --workspace --all-targets --all-features` passes                                                                                                                                     | pass   |
| Pinned dependency versions                                   | `ratatui = "=0.30.2"` and `crossterm = "=0.29.0"` in `Cargo.toml` / `Cargo.lock` — latest stable at time of T1; only `siralos-cli` depends on them                                                                                                                                                                                  | pass   |
