# 121 — The Provider Config Flow Entry Review

Ticket [108](../tickets/108-tui-provider-config-flow.md) · entry review [103](103-siralos-tui-entry-review.md) · Map.

> **User-directed 2026-08-31 (session HITL).** The config-write authority for the provider add-flow is GRANTED (the user continued ticket 108): /provider gains an add-flow that collects provider/model/credential-env-name/endpoint and writes the [profile] section into siralos.toml atomically with format-preserving merge — never credential values, only the env-var name. Also: the command palette retains while typing and Tab completes the prefix, and a blank line separates the ASCII banner from the greeting. The live spinner is answered as an explanation and recorded OPEN.
