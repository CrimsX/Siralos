# 99 — Activation B3b: Default-Off Session Wiring

Governing plan 68 · entry review [95](95-context-activation-entry-review.md) · Map.

> **User-directed 2026-08-31 (session HITL).** B3b of the approved activation arc: the additive [profile.context_system] key (distinct from the decision 54 controls key) opts a session into the read-only context subsystem — WorkspaceContext build, the three context tools registered over the derived snapshot, and the demand loop driven after each tool round; absent key or enabled=false is byte-transparent; build failure is a diagnostic with the subsystem off; the model can never inject events or scores; nothing persists and nothing renders — B4 owns the audit surface.

## 2. Design (W1–W7) — default-off session wiring

| Design                                     | Detail                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| W1 PROFILE KEY                             | Additive `[profile.context_system]` table with exactly one key `enabled: bool` (default `false` when the table is absent; a present table without a valid boolean `enabled` leaves the whole profile UNAPPLIED — the established malformed-leaves-unapplied pattern, decision 48 C3). Distinct from decision 54's `[profile.context]` CONTROLS key; both may coexist. The composition carries the opt-in as a bounded, narrowing-only enablement authorizing read-only context machinery only: a widening interpretation is impossible by construction — the key adds no capability beyond registering read-only tools and updating an in-memory working set. `ProfileRecord.context_system_enabled`.                                                                                                                  |
| W2 ON PATH                                 | When the applied profile has `context_system.enabled = true`, the session startup calls `build_workspace_context` over the session workspace root with `DEFAULT_SCAN_BOUNDS`; on success the session holds the `WorkspaceContext`, builds the initial scheduler working set over the classified graph (`WorkingSetState` over the graph nodes), registers the three read-only context tools (`context.search` / `context.inspect` / `context.expand`) in the session tool registry over the derived `ContextToolState` snapshot, and after EACH completed tool round derives host-observed observations -> `compose_tick_input` (events + search scores) -> `process_tick` -> working-set update (coalescing applies; no-op ticks are skipped naturally). The deterministic clock port supplies the tick `now` values. |
| W3 OFF PATH                                | Absent key or `enabled=false`: byte-transparent — no scan, no graph, no tools registered, no ticks; the session behaves exactly as before B3b (test-pinned byte-equality of session-visible behavior where the harness exposes it).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| W4 FAIL-CLOSED                             | Any `WorkspaceContext` build failure (typed `unavailable`) records a host-side diagnostic and the session continues with the subsystem OFF — never fatal, never partial (no tools are registered if the build failed).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| W5 NO INJECTION                            | Events and search scores derive ONLY from host-executed tool results via the existing helper signatures `compose_tick_input` / `derive_events_for_tick` / `derive_search_scores_for_tick`; the model can never inject either (compile-level barrier + test-pinned). `                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| W6 NO PERSISTENCE / NO RENDERING           | Nothing is written; no output-format changes — B4 owns the audit surface.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| W7 ADVERSARIAL CRITERION (95 C3, B3b form) | The session's demand path can only produce canonical bounded `TickInput`s (<= 64 events, <= 64 search scores, host-observed only) — test-proven at the composition seam; the scheduler-side invariants (quota, stale-never-promote, ring cap) stand from decisions 89–93 and are not re-proven here.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
