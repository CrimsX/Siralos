## 3. TerminalSanitizer gap — how to judge `drain_events`

**Context:** `crates/siralos-cli/src/interactive.rs:253-295` `drain_events` writes `ToolLoopEvent::TextDelta { text }` raw via `writer.write_all(text.as_bytes())` and `ResponseFailed { message }` via `format!("Response failed: {message}")` without a sanitizer. The TypeScript path treats `apps/cli/src/output/sanitize.ts` (`TerminalSanitizer`) as the **single output boundary** per `apps/cli/AGENTS.md` and `ARCHITECTURE.md` — every byte (provider responses, filenames, checkpoints, errors) passes through C0/C1, CSI, OSC 8, CR/BS, surrogate-pair neutralization.

**Decision (this ticket):** **Raw write is acceptable for R7.5 PASS** — but it must be recorded as a **security advisory with a follow-up ticket**, not silently passed.

Rationale:

- The only provider in the R7.5 composition is `DeterministicFakeProvider` (`crates/siralos-adapters/src/provider/deterministic_fake.rs`) — deterministic echo `Siralos received: <prompt>` chunked at 16 code points, with synthetic `workspace.*` tool scenarios. Its output is bounded by `siralos-core::provider::turn` (7 dimensions) and is not arbitrary network data. The risk in this slice is low.
- However, the **contract** (`docs/development/R7_BEHAVIOR_EXTRACTION.md` §2.1.1, §10) states _provider output is always untrusted data_ and the sanitizer is the **single** terminal boundary. A future real provider would violate this contract if the gap persists.
- Therefore: **PASS** the candidate, but file an advisory and schedule hardening **before any real provider lands** (R11 or earlier). The follow-up must wrap `drain_events` (and potentially `format_context_status` if it ever renders untrusted content) through a Rust port of `TerminalSanitizer` (`sanitize.ts:1-147`), preserving its chunk-split surrogate handling and CSI/OSC state machine.

**Follow-up ticket to create on close:** `Advisory: port TerminalSanitizer to siralos-cli drain path` — priority P2, blocks real-provider milestone, not R7.5.

**FAIL if:** a reviewer promotes R7.5 without acknowledging the gap in the review notes.
