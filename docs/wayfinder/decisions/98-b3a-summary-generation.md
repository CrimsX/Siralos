# 98 — Activation B3a: Deterministic Summary Generation

Governing plan 68 · entry review [95](95-context-activation-entry-review.md) · Map.

> **User-directed 2026-08-31 (session HITL).** B3a of the approved activation arc: scanned nodes gain deterministic L1 summaries via the R5 advisory summary formatter — pure functions of file content under the existing bounds, composed with the B1 scan and B2 classification into a host-side WorkspaceContext; nothing persists, nothing renders, nothing wires — B3b consumes it behind the default-off profile key.

## 2. Design (G1–G4) — deterministic L1 summaries

| Design                 | Detail                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| G1 BUILD PIPELINE      | A new pure composition `build_workspace_context(root, bounds) -> Result<WorkspaceContext, typed unavailable>` in `crates/siralos-adapters/src/context_scan.rs`: (1) the B1 scan unchanged byte-for-byte (`scan_workspace_with_bounds`); (2) the B2 classification binding (`bind_scan_to_graph` via `classify_node`); (3) for EACH admitted node a bounded re-read via the established exact-read primitive `read_complete_file_bounded` with the same `max_file_bytes` bound (oversized files were already skipped at scan time so no node needs one) producing the L1 summary via the R5 deterministic advisory summary formatter over the file content; (4) the result carries the classified graph nodes PLUS per-node L1 summaries wired into the decision 80 representation-store seam (`L0 digest + L1 summary` available per node via `ContextRepresentationStore` with `Identity` + `Summary` `HostExtracted`; nothing above L1; `L2` host-only untouched). |
| G2 SUMMARY DETERMINISM | Summaries are pure functions of file content; the R5 formatter's own deterministic bounds apply (`DEFAULT_SUMMARY_MAX_BYTES = 4096`, `SUMMARY_FOOTER`, `SUMMARY_TRUNCATION_MARKER`, `utf16_len`/`utf16_prefix_*` truncation — no new truncation invented); identical content produces identical summaries across runs; dedup property: two files with identical content produce identical L1 summaries (pinned by `build-summaries-dedup`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| G3 NO NEW SURFACES     | No CLI rendering, no session wiring, no tool registration, no scheduler changes — `WorkspaceContext` is a host-side data structure proven by tests and the differential scenarios; B3b will consume it behind the default-off profile key; no model-visible surface yet.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| G4 STALENESS           | Still out of scope (arrives with session-held prior state in B3b/B4).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
