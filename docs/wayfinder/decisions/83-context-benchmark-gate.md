# Decision 83 — The Context Benchmark Decision Gate (Slice 5)

**Governing plan:** [68 — Real Provider Credentials and Registry](68-real-provider-credentials-and-registry.md) · **Entry review:** [79](79-context-management-foundations.md) · **Map:** [Siralos Roadmap](../siralos-roadmap.md)

> **User-directed 2026-08-31 (session HITL).** Slice 5, frozen clause (g): the deterministic benchmark gate over the real tool path. Key-blind paged strategy, integer-only metrics, a broad-query scenario where paging cannot win, and a mechanical GO rule. The verdict is measured, not asserted; the follow-up metrics seam is built only on GO.

## 2. Methodology

| Aspect                 | Rule                                                                                                                                                                                                                                                                                                                                                                                 |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Baseline               | Surface every node's L0 identity content; `tokens_baseline = sum estimate(L0 content bytes) over all nodes`; `recall_baseline =                                                                                                                                                                                                                                                      | key                                            | ` (requires L0)                    |
| Paged flow (key-blind) | (1) `search {query}` → hits canonical by `node_id`, cap 16; (2) `inspect` every hit → summary bytes count; (3) `expand` every hit at best level priority `structured > detailed > summary > identity` (no levels → only inspect); `tokens_paged = estimate(sum expanded bytes + sum inspect summary bytes) + 4 * tool_calls` where `tool_calls = 1 search + hits inspects + expands` |
| Estimator              | `estimate_tokens(bytes) = ceil(bytes / 4)` (`TOKEN_BYTES_PER_TOKEN=4`); the only estimator, every number flows through it                                                                                                                                                                                                                                                            |
| Overhead               | `TOOL_CALL_OVERHEAD_TOKENS=4` per tool call                                                                                                                                                                                                                                                                                                                                          |
| Recall                 | `recall_paged =                                                                                                                                                                                                                                                                                                                                                                      | key nodes that appear in hits AND got expanded | `; flow never reads the answer key |
| GO rule                | `go = (total_recall_paged == total_recall_baseline) && (total_paged * 2 < total_baseline)`                                                                                                                                                                                                                                                                                           |

## 4. Result

The gate measured NO-GO (total_baseline 1230 vs total_paged 650, recall 14/14, `total_paged *2 < total_baseline` false — total_recall_paged 14 == total_recall_baseline 14 is true, total_paged 650 *2 < total_baseline 1230 is false => NO-GO). The program closes at the gate; the audit and metrics seam is not justified by the measured evidence.
