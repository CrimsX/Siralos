# 96 — Activation B1: The Bounded Workspace Scan

Governing plan 68 · entry review [95](95-context-activation-entry-review.md) · Map.

> **User-directed 2026-08-31 (session HITL).** B1 of the approved activation arc: a bounded, deterministic, read-only workspace scan producing graph-reconstruction material over the existing digest seams — protected and oversized paths skipped and counted, node cap with deterministic truncation, no partial reads, no persistence, typed unavailability; the graph binding is provisional until the B2 taxonomy review; staleness marking is out of scope until session state exists.

## 2. Design (S1–S5) — pinned bounds

| Design                         | Detail                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| S1 BOUNDS                      | `ScanBounds { max_nodes: 256, max_file_bytes: 65536 }` — pinned constants in the record.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| S2 SCAN                        | `scan_workspace(root, bounds) -> Result<BoundedScan, typed unavailable>` — deterministic walk via the existing bounded workspace list primitive in LEXICOGRAPHIC relative-path order. For each regular file in order: if the relative path is PROTECTED (any-depth `AGENTS.md`, `.siralos/**`, `.git/**`) -> counted in `protected_skipped`, no node; else if file size > `max_file_bytes` -> counted in `oversized_skipped`, no node (no partial reads — an oversized file never contributes a digest); else read via the bounded exact-read primitive, compute the content digest over the EXISTING identity primitive, and append `ScanNode { relative_path, content_digest, byte_len }`. Node cap: stop admitting nodes at `max_nodes`; if candidate files remain, set `truncated=true` and count `files_not_scanned`. Output `BoundedScan { nodes (lexicographic order), protected_skipped, oversized_skipped, files_not_scanned, truncated }`. |
| S3 READ-ONLY                   | The scan performs no writes, no spawns, no persistence; it composes existing read primitives only.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| S4 GRAPH BINDING (provisional) | A pure fn binding `ScanNodes` into the decision 79 `ContextGraph` node types using the graph's existing default/Source-kind node constructor. The record states plainly: B1's binding is provisional; the B2 taxonomy review revisits kinds and per-kind bounds.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| S5 STALENESS                   | OUT OF SCOPE for B1 — staleness marking arrives with session-held prior state (B3/B4). ScanNodes carry digests only.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
