# 123 — The TUI Interaction Pass Entry Review

Ticket [109](../tickets/109-tui-interaction-pass.md) · entry review [103](103-siralos-tui-entry-review.md) · Map.

> **User-directed 2026-08-31 (session HITL).** The third live-usage round: the palette still fails to retain while typing — root-caused as a wiring gap (the unit test exercised update_palette directly, but the live handle_key never calls it after input edits), plus arrow-key palette navigation with Enter/Tab selection, full command display, command history via Up/Down, a /models fetch from the provider (a new network surface with the freeze documented), and a right-edge layout gap fix.
