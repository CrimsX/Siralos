# 119 — The TUI UX Pass 2 Entry Review

Ticket [107](../tickets/107-tui-ux-pass-2.md) · entry review [103](103-siralos-tui-entry-review.md) · Map.

> **User-directed 2026-08-31 (session HITL).** The second usability round from live TUI usage: the header stops duplicating the bottom status when no provider is configured, an ASCII banner and greeting greet the session, the palette filter is verified as typing, timestamps move from UTC to the user's local timezone via the time crate (a new CLI-only dependency, recorded), and the loading indicator is addressed within the synchronous architecture — a live spinner during a blocking model round requires a UI thread, which is presented as an open architecture question rather than implemented.
