## 1. Domain neutrality — siralos-core must never depend on infrastructure or a domain

### Enforcement (mechanical, in CI)

| Enforcement                                                    | File:line                                                                                                                              | What it does                                                                                                                                                                                        | Where a Godot type is caught                                                                                                                                                             |
| -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `unsafe_code = "forbid"` workspace lint                        | `Cargo.toml:15`                                                                                                                        | Whole workspace forbids unsafe; `siralos-core` cannot introduce unsafe Godot bindings                                                                                                               | Any unsafe FFI would fail `cargo clippy` / `check:rust`                                                                                                                                  |
| Crate shape + dependency direction                             | `scripts/check-rust-architecture.mjs:11-58` (crate list, allowed deps)`                                                                | Expected crates exactly `crates/siralos-core`, `crates/siralos-adapters`, `crates/siralos-cli`; allowed edges `core: ∔`, `adapters: {core}`, `cli: {core, adapters}`                                | `scripts/check-rust-architecture.mjs:246-247` rejects `siralos-core` having **any** workspace dependency — a Godot crate would have to be added as a workspace dep and immediately fails |
| Godot symbol scan in `siralos-core` sources                    | `scripts/check-rust-architecture.mjs:29-31` `FORBIDDEN_CORE_SYMBOL_PATTERN = /godot                                                    | gdscript                                                                                                                                                                                            | \\.tscn                                                                                                                                                                                  | \\.tres | project\\.godot | nodepath | autoload/i`+`282-283` | Scans every `crates/siralos-core/src/**` file; error `"siralos-core must stay domain-neutral (Godot symbol present)"` | Adding `GodotSceneModel`, `gdscript`, `.tscn` literal, or `NodePath` type to core sources is caught at `npm run check:rust` |
| Language neutrality (R5) — no GDScript/Godot semantics in core | `scripts/check-rust-architecture.mjs:40-49` `FORBIDDEN_CORE_LANGUAGE_PATTERN` + `FORBIDDEN_CORE_LANGUAGE_SEMANTIC_PATTERN` + `285-298` | Forbids LSP transport, process/socket, async runtime, and GDScript semantic vocabulary in `siralos-core` (production language modules)                                                              | A core file importing `lsp`, `tokio`, `wasmtime`, or carrying `SignalInfo` / `class_name` semantics fails                                                                                |
| Core Cargo manifest — no Godot deps                            | `crates/siralos-core/Cargo.toml:1-12`                                                                                                  | `[dependencies]` has exactly one entry: `serde_json = "1"` (JSON at provider/tool-result boundary, R7.1). No Godot crate, no adapter, no CLI dep                                                    | Adding `siralos-adapters = {…}` or a future `siralos-godot` dep would be a workspace dependency and fail the check above                                                                 |
| Core lib header — documented neutrality                        | `crates/siralos-core/src/lib.rs:1-22`                                                                                                  | Module header states `"must never depend on adapter infrastructure or on a domain"` + lists `pub mod domain/identity/language/projection/provider/task/tool/version/workspace` — no `pub mod godot` | A reviewer seeing `pub mod godot` in core lib would have a spec violation before CI even runs                                                                                            |
| TypeScript parallel ownership                                  | `AGENTS.md:16-19` + `ARCHITECTURE.md:189-271`                                                                                          | `@siralos/core` owns domain contracts; `@siralos/adapters` implements Godot ports — same inward pattern in both languages                                                                           | Mirrors the Rust rule; TS Godot files live under `packages/core/src/godot/` + `packages/adapters/src/godot/` but Rust core has no counterpart                                            |

### What a violating addition looks like

`crates/siralos-core/src/godot/mod.rs` containing `struct GodotNode` or `use godot::Scene` → `npm run check:rust` exit 1 listing every offending file:line with the Godot-symbol message. Dependency addition `siralos-core = { path = "../siralos-godot" }` → `check-rust-architecture` exit 1: `"forbidden workspace dependency"`.

## 2. R4 hardening — why mutation/checkpoint creation remain unavailable

R4 is the generic workspace/project foundation. Its hardening is **fail-closed** — the stack intentionally reports `unavailable` where the filesystem cannot mechanically bind the operation to the exact object.

| Concern                                                 | Core primitive (validation/classification)                                                                                                                                                                                                     | Adapter enforcement (containment/bounded read)                                                                                                                                                                                                                                                                                                                                                           | Why R8/R9 cannot lift it without a separate primitive                                                                                                                                                                                                                                                                                                                                                                      |
| ------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Traversal / absolute / drive**                        | `crates/siralos-core/src/workspace/path.rs:6-132` — `PathValidationError::{NullByte,Absolute,ParentTraversal}` via `is_absolute_pattern` (`^(?:[A-Za-z]:)?[\\/]` + `^[A-Za-z]:`)                                                               | Adapters resolve via canonical root + containment check (not shown here but covered by differential `workspace-read.symlink.escape` corpus)                                                                                                                                                                                                                                                              | Upstream of every read/write; a `../` or `C:\` payload never reaches the filesystem                                                                                                                                                                                                                                                                                                                                        |
| **Protected behavioral config**                         | `crates/siralos-core/src/workspace/path.rs:138-197` `is_protected_behavioral_config_path` + `is_protected_write_target` — `AGENTS.md` at any depth and `.siralos/**` are rejected before any write, approval, or checkpoint; `SECURITY.md:145` | All mutation surfaces (change-set validator, standalone create/edit/delete targets) reject before write                                                                                                                                                                                                                                                                                                  | Even approved mutations cannot touch behavioral config — future dedicated path TBD, never offered now                                                                                                                                                                                                                                                                                                                      |
| **Symlink/junction escape**                             | N/A — classification only                                                                                                                                                                                                                      | `crates/siralos-adapters/src/workspace/checkpoint.rs:143-149` root lstat + is_symlink check; `crates/siralos-adapters/src/workspace/checkpoint.rs:745-785` `workspace_file_state` — leaf `symlink_metadata`, is_symlink → fail closed; `crates/siralos-adapters/src/workspace/checkpoint.rs:1011-1039` test `workspace_file_state_fails_closed_on_parent_link_escape` with real directory symlink escape | A checkpoint record pointing outside the workspace is never followed — `symlink_metadata` on the parent component detects link escape before any open                                                                                                                                                                                                                                                                      |
| **Bounded complete exact reads** (never short-read EOF) | Bounds via `siralos-core::workspace` reference bounds (R4)                                                                                                                                                                                     | `crates/siralos-adapters/src/workspace/fs.rs:4-83` — authoritative read is **lstat-verified first** (non-regular → fail), then **read until EOF or cap**, retrying `Interrupted`, so one short read **never** treated as EOF; complete stream returned only when EOF was observed at ≤ `max_bytes`                                                                                                       | Prevents partial-prefix identity; corpus covers exact/over-boundary, short-read regression                                                                                                                                                                                                                                                                                                                                 |
| **Fail-closed mutation/checkpoint**                     | `siralos-core::workspace` prepared create/edit/delete effect models (typed, revision-bound, immutable)                                                                                                                                         | Adapters report `unavailable` before approval, checkpoint creation, or spawn — no pathname-based write is offered                                                                                                                                                                                                                                                                                        | `SECURITY.md:210-224` — Node/Rust without directory-relative openat/renameat cannot atomically displace→quarantine→commit with handle-bound exclusive create; a same-user process can swap parent/target between verification and create, and cleanup could delete a substituted object. Until an identity-bound primitive exists, every `workspace.create_file/edit/delete` and new checkpoint is `unavailable` by design |

**Differential evidence:** `tests/differential/corpus/workspace-read.exact.basic.json`, `.binary.json`, `.symlink.escape.json`, `checkpoint.inspection.json`, `git-inspection.*` — all required applicable scenarios match per `docs/development/RUST_MIGRATION.md` R4 paragraph (23 scenarios, corpus v7, 47 files).

## 3. Godot static inspection — adapter-owned vs core-owned

### What exists today (TypeScript reference = oracle; Rust = Siralos host only)

| Surface                              | TypeScript core contracts                                                                                                                                                                                              | TypeScript adapter implementation                                                                                                                                                                                                                        | Rust placement                                                                    | Authority                                                                                                                           |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| **Engine discovery**                 | `packages/core/src/godot/installations.ts`, `version.ts`, `engine-profile.ts`, `capabilities.ts`, `compatibility.ts`, `selection.ts` (version/edition/capability model, deterministic selection policy with rationale) | `packages/adapters/src/godot/config/selection-request.ts`, `godot-inspector.ts`, `cache/engine-profile-cache.ts` (configured paths + fixed-name PATH search, macOS `.app` bundle, version parsing, static project detection every inspection — no cache) | **Not ported** — owned by R8; `crates/siralos-core` has no godot module (see §1)  | Core owns models/ports/selection policy; adapters own discovery/parsing/FS                                                          |
| **Engine probing (fail-closed)**     | `packages/core/src/godot/probe.ts`, `probes.ts` (`GodotProbeRunner` port, fixed `"--version"/"--help"/"--dump-extension-api"` tuples via private `fixedProbeArguments` constructor)                                    | `packages/adapters/src/godot/*.ts` fixed runners — reports `unavailable` for every probe, never spawns Godot (backend would re-open staged copy's pathname; no exec-by-handle primitive exists — same-user swap between verification and launch)         | **Not ported** — owned by R8; adapter-owned, never invoked at R8 before hardening | Only Godot probe adapter may invoke engine, always through `SandboxBackend`; at R7 nothing spawns Godot (`ARCHITECTURE.md:418-420`) |
| **API knowledge**                    | `packages/core/src/godot/knowledge.ts`, `api.ts` (version-bound dump model, parser/index/search/lookup contracts)                                                                                                      | `packages/adapters/src/godot/api-dump/*`, `godot-knowledge-runner.ts` (`--dump-extension-api-with-docs`)                                                                                                                                                 | **Not ported** — owned by R8                                                      | Fail-closed (ADR 0010) — no dump generation without engine probe                                                                    |
| **GDScript diagnostics**             | `packages/core/src/godot/diagnostics.ts`, `gdscript.ts` (diagnostic normalization contracts)                                                                                                                           | `packages/adapters/src/godot/diagnostics/*` (script enumeration, `diagnostic-normalizer.ts`, `godot-diagnostics-service.ts`, `prepared-check-store.ts`)                                                                                                  | **Not ported** — owned by R8/R9                                                   | Fail-closed at R7                                                                                                                   |
| **LSP / language service**           | `packages/core/src/godot/lsp.ts` (bounded LSP framing, URI mapping, session lifecycle)                                                                                                                                 | `packages/adapters/src/godot/lsp/*`                                                                                                                                                                                                                      | **Not ported** — owned by R8/R9                                                   | Requires process execution — fail-closed                                                                                            |
| **Scene/resource intelligence**      | `packages/core/src/godot/development/` (`blocked-disposition.ts`, `cross-surface-consistency.ts`, scene/resource models)                                                                                               | `packages/adapters/src/godot/development/*` (change-set preparation/executor, `gdscript-development-service.ts`, `unified-development-service.ts`)                                                                                                       | **Not ported** — owned by R9                                                      | Static parsing intact; application with verification remains unavailable                                                            |
| **Host-generic context (NOT Godot)** | `crates/siralos-core/src/projection/*`, `siralos-core::workspace`, `siralos-core::task`, `siralos-core::language` (one-based positions, sanitized diagnostics, symbol/reference models)                                | R4 workspace adapters (`crates/siralos-adapters/src/workspace/*`), R7.3 projection, R7.4 config                                                                                                                                                          | **Current Rust surface** — domain-neutral, ships now                              | Host stays small; optional domain adds intelligence without acquiring host authority (ADR 0036)                                     |

### Key quote — ownership stays small

> `ARCHITECTURE.md:414` — "Core owns the Godot models … and the `GodotProbeRunner` / `GodotInspector` ports. Core never discovers, invokes, parses, or stores anything itself."
> `ARCHITECTURE.md:420` — probe argument discipline: exactly three fixed tuples from the single `fixedProbeArguments` private constructor; `--path/--import/--scene/--editor` never used; enforced by `npm run check:architecture`.

## 4. ADR 0036 lean constraint — no marketplace, no auto-installed Godot
